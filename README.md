# Twixters.Co — Official Website

Modern, high-performance portfolio and brand studio website for **Twixters.Co**, built with a clean frontend stack.

## Tech Stack

- **Framework**: React 19 (JavaScript / JSX)
- **Styling**: Tailwind CSS v4
- **Build Tool**: Vite 7
- **Typography**: Poppins (Display/Hero) & DM Sans (Body/UI)
- **Deployment**: Vercel-ready static build (`dist/`)

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Local Development

```bash
npm run dev
```

The site will be available at `http://localhost:5173/`.

### Production Build

```bash
npm run build
```

The production-ready static assets are generated in the `dist/` directory, ready for immediate deployment to Vercel, Netlify, or any static host.

### Preview Production Build

```bash
npm run preview
```
